# Vitrines « menu éclaté » des restos : les photos à faire avec ChatGPT

Même travail que pour Rendez-Vous : le plat entier au centre, ses ingrédients autour ; le client touche un ingrédient pour l'enlever.
Smash It est déjà fait. Les photos des vrais plats sont dans `restos-photos/` (je te les envoie aussi).

## Ce que je fais moi-même (rien à faire pour toi)
- **McDonald's casher** (Big Mac, Mac Royal, Mega Crispy Chicken) : leurs photos sont déjà sur fond blanc, je les découpe.
- **Nina Sushi** (roll saumon avocat, poke bowl, sushi frit) : photos déjà isolées sur fond noir, je les découpe.
- **Pizza Crush** (Margherita, légumes, truffe) : pizzas vues de dessus, je les découpe.
- Les couleurs, le placement, la vérification casher, la vidéo pour toi.

Pour chacun : joindre **sa photo du vrai plat**, puis copier ce texte :

> Refais ce plat en photo publicitaire professionnelle : exactement le même plat, mêmes ingrédients. Plat entier, vu de 3/4, détouré sur fond transparent (PNG). Éclairage studio doux, très appétissant, couleurs naturelles. Aucun texte, aucun logo, aucune main, aucune boisson, aucune frite à côté, aucune assiette ni planche. Format carré 1024 × 1024.
