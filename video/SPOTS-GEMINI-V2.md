# Spots HOP! v2 : toutes les images à refaire (patron, 09/11)
Vraies marques + produits qui entrent naturellement dans le sac.

## Règles pour Gemini (important)
- **UNE image par message, en grand.** Pas de planche avec plusieurs vues : chaque vue en plein format.
- Une conversation par objet. Garder la 1re image jointe à chaque message (même objet sous tous les angles).
- Si une vue ne ressemble plus à la 1re (couleur, forme, logo), la refaire.
- Pour les produits de marque : joindre une vraie photo du produit (appli HOP!, rayon Carrefour, ou carrefour.co.il).
- Les effets de lumière, le studio, le bokeh, les poussières et l'éclat sont déjà bons : rien à refaire.

## Texte de base (au début de chaque image d'objet)
```
Photographie produit de studio, hyper réaliste, 4K, format carré 2048×2048. Fond gris clair uni, parfaitement plat, sans décor. Éclairage de studio : grande lumière douce en haut à gauche, liseré lumineux orange chaud sur le bord droit, reflets nets. Objectif 85 mm, objet entier, centré, jamais coupé, avec beaucoup de marge autour.
```

```
[texte de base] [PRODUIT], avec son emballage exact comme sur la photo jointe (logo, couleurs, textes nets et lisibles). Vue [de trois quarts / de profil / d'en dessous en contre-plongée]. Le produit flotte légèrement incliné, comme en train de tomber. Une seule vue en plein format.
```
