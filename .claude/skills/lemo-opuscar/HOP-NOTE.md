# Lemo-Opuscar (ajouté le 24/11/2026, demande du patron)

Bibliothèque de 99 styles de films faits entièrement en code (https://github.com/lemomo-ai/lemo-opuscar, par Lemomo / LemoLab).
On demande : « Fais un film de 30 s dans le style <nom> sur HOP! … » ; au premier usage le script `scripts/setup.sh` télécharge
la bibliothèque dans ~/lemo-opuscar (Node, ffmpeg, Python nécessaires).
