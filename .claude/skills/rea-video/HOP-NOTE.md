# rea-video (ajouté le 23/11/2026, demande du patron)

Outil libre (Apache-2.0) de https://github.com/JuneYaooo/rea-video : on lui donne une vidéo (pub, Reel, TikTok)
et il la démonte plan par plan (filmé, IA, animation, sous-titres, musique, rythme) et propose comment la refaire.
Pour HOP! : refaire une pub qui marche, en version HOP! avec nos vidéos Remotion (`video/`) et Hoppy.

Le programme lui-même (`rea-video`, Python ≥ 3.10 + ffmpeg) s'installe à part, avec l'accord du patron :
`pip install "git+https://github.com/JuneYaooo/rea-video#egg=rea-video[ocr]"`.
Ne jamais citer un concurrent dans ce qu'on refait ; textes FR + HE ; règles de CLAUDE.md.
